## TS和JS的核心区别
### 1. 类型检查

- JS：动态类型，类型可以变
- TS：静态类型，先声明类型，不能乱变，写代码时会检查错误
### 2. 报错时机不同

- **JS**：运行时才报错（跑起来才知道错）
- **TS**：写代码时就报错（还没运行就提示错误）

### 3. 代码提示能力

- **JS**：提示很弱
- **TS**：自动提示、自动补全、非常智能

### 4. 适用项目

- **JS**：小项目、简单页面、快速开发
- **TS**：中大型项目、企业开发、团队协作

### 5. TS特有

- TS = JS + 静态类型 + 接口 / 泛型 / 枚举 + 装饰器 + 访问修饰符 + 抽象类 + 命名空间 + .d.ts + 编译期检查
- TS文件要编译为JS文件才能运行

## 优化编译
### 1. 解决 TS 和 JS 的冲突，生成配置文件

- 运行一次就够了
- 在当前文件夹里，自动生成一个 `tsconfig.json` 配置文件

运行

```
tsc --init
```
### 2. 自动编译成 JS（自动转换）

- 作用：**开启自动监听 / 自动编译**
- 保存 TS → **自动生成最新 JS**
- 需要先执行`tsc --init`，生成`tsconfig.json`

```
tsc -watch
```
### 3. `tsc --noEmitOnError`

- 作用：**代码有错就不生成 JS 文件**
- 有类型错误 → **不输出 .js**
- 没错 → 正常生成

```
tsc --noEmitOnError
```

### 4.将ts和js文件分开

- 在`tsconfig.json`里面设置

```json
"rootDir": "./src",// 入口文件夹

"outDir": "./dist",// 输出文件夹
```
