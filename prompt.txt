角色定义

你是一位经验丰富的前端开发工程师，精通 React 生态系统和 GitHub Pages 部署。你将从零开始为我生成一个完整的、可直接部署的个人技术博客网站。

项目概述

创建一个现代化的个人技术博客，用于分享学习笔记、技术思考和项目经验。网站将部署到 GitHub Pages，支持响应式设计，在手机、平板和桌面设备上都能良好显示。

我的技术博客使用 React 18 + TypeScript + Vite + Tailwind CSS，部署到 GitHub Pages。请为我完整配置 Markdown 渲染，同时支持 LaTeX、代码高亮和图片显示，要求如下：

一、整体技术栈（必须统一）
- 核心：react-markdown + remark-math + rehype-katex + katex（LaTeX）
- 代码：react-syntax-highlighter（Prism）+ 复制按钮 + 语言标签
- 图片：原生 img 增强 + 懒加载 + 自适应宽度 + 点击预览
- 全部兼容深色/浅色模式，移动端友好

二、LaTeX 公式（已有的功能，保留并兼容）
- 行内：$E=mc^2$
- 块级：$$\int_0^\infty e^{-x}dx=1$$
- 自动引入 katex 样式，不错位、不丢符号

三、代码块支持（重点增强）
1. 语法高亮：支持 js/ts/python/java/go/html/css/sql 等常见语言
2. 渲染样式：深色主题（如 dracula），和整体博客风格协调
3. 附加功能：
   - 自动显示语言标签（右上角）
   - 右上角“复制”按钮，点击复制代码并提示
   - 代码块自适应宽度，横向滚动（长代码）
   - 行内代码 `code` 保持原样样式

四、图片显示支持（重点增强）
1. 基础渲染：兼容 Markdown 标准语法 ![alt](url)
2. 自适应：图片默认最大宽度 100%，高度自动，不溢出
3. 懒加载：所有图片默认开启 loading="lazy"，提升性能
4. 点击预览：点击图片可放大查看（简单弹窗即可）
5. 路径兼容：支持绝对 URL、相对路径（如 /assets/xxx.png），适配 GitHub Pages 部署

五、组件整合
- 新建/修改 MarkdownRenderer.tsx，统一集成 LaTeX、代码高亮、图片处理
- 所有依赖在 package.json 中声明，安装命令：
  npm install react-markdown remark-math rehype-katex katex react-syntax-highlighter
- 提供一篇完整测试博文，包含：
  - 2 处 LaTeX（行内+块级）
  - 3 种代码块（js/python/html）
  - 2 张图片（远程URL+相对路径）
- 确保无冲突、可直接运行、build 正常、GitHub Pages 部署后正常显示

六、输出要求
直接生成完整可运行的代码文件（包括组件、依赖、测试文章），不需要我手动改配置。用中文写注释，结构清晰。

核心功能

1. 首页

	•	个人简介区域：头像、姓名、职业、简短介绍
	•	最新博客列表：显示最近发布的 3-5 篇博客文章
	•	精选项目展示：展示 2-3 个重要项目
	•	快速导航：指向博客列表、项目页面和关于页面的按钮

2. 博客列表页

	•	文章卡片：显示文章标题、摘要、发布日期、阅读时间、分类和标签
	•	搜索功能：支持按文章标题和内容搜索
	•	分类筛选：按文章分类筛选
	•	标签云：显示所有文章标签，点击可筛选
	•	分页功能：每页显示 10 篇文章
	•	排序选项：按发布日期或阅读量排序

3. 博客详情页

	•	Markdown 内容渲染：支持完整的 Markdown 语法
	•	代码高亮：支持多种编程语言的语法高亮
	•	代码复制功能：每个代码块右上角添加复制按钮
	•	目录导航：自动生成文章目录，支持点击跳转和滚动高亮
	•	文章信息：标题、发布日期、阅读时间、分类、标签
	•	上一篇 / 下一篇导航
	•	返回顶部按钮

4. 项目展示页

	•	项目卡片：显示项目名称、描述、截图、技术栈
	•	项目链接：GitHub 仓库链接和在线演示链接
	•	技术栈标签：使用彩色标签显示项目使用的技术
	•	筛选功能：按技术栈筛选项目

5. 关于我页

	•	个人信息：头像、姓名、职业、联系方式
	•	技能展示：使用进度条或标签云展示技术技能
	•	工作经历：时间线形式展示工作经验
	•	教育背景：展示学历信息
	•	社交媒体链接：GitHub、LinkedIn、Twitter 等

6. 通用组件

	•	导航栏：响应式设计，移动端显示汉堡菜单
	•	深色模式切换：支持浅色 / 深色 / 系统主题
	•	页脚：版权信息、网站地图、社交媒体链接
	•	404 页面：友好的错误页面

设计风格

	•	整体风格：简洁、专业、现代，适合技术博客
	•	配色方案：
	◦	主色调：蓝色系（#3b82f6），代表专业和信任
	◦	辅助色：绿色（#10b981）用于成功状态，红色（#ef4444）用于错误状态
	◦	中性色：白色、浅灰、深灰、黑色，用于文本和背景
	•	
	•	排版：
	◦	标题：使用 Inter 字体，粗体，清晰的层级结构
	◦	正文：使用 Inter 字体，行高 1.6，易于阅读
	◦	代码：使用等宽字体，如 Fira Code
	•	
	•	动画效果：
	◦	页面切换时的淡入淡出效果
	◦	卡片悬停时的轻微缩放和阴影变化
	◦	按钮点击时的反馈效果
	◦	平滑滚动

代码规范

	•	使用 TypeScript 进行类型检查，所有组件和函数都要有明确的类型定义
	•	使用 ESLint 和 Prettier 进行代码格式化和风格检查
	•	组件使用函数式组件和 React Hooks
	•	使用路径别名@/指向src目录，简化导入
	•	代码注释清晰，关键逻辑要有详细说明
	•	组件命名使用 PascalCase，函数和变量使用 camelCase
	•	文件名与组件名保持一致

响应式设计

	•	使用 Tailwind CSS 的响应式前缀（sm:, md:, lg:, xl:, 2xl:）
	•	移动端优先设计，确保在小屏幕上有良好的体验
	•	导航栏在移动端转换为汉堡菜单
	•	卡片布局在不同屏幕尺寸下自动调整列数
	•	文本大小和间距根据屏幕尺寸自适应
